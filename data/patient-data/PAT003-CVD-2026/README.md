# PAT003-CVD-2026 — Preventive Cardiovascular Health

Synthetic patient profile: 67-year-old post-menopausal woman with controlled
hypertension and bilateral family history of cardiovascular disease.

This is a representative case for the "healthy aging, 65+ female" demographic —
a population significantly underrepresented in cardiovascular clinical research.

All data in this directory is synthetic and generalized to represent a
population-level use case, not any specific individual.

## Files

| File | Description |
|------|-------------|
| `clinical/pat003_profile.json` | Full clinical profile with biomarkers, medications, risk scores |

## Use case

Unlike PAT001 (acute oncology, HGSOC) and PAT002 (ER+ breast cancer), PAT003
is a **preventive health** profile. The goal is 10-year cardiovascular risk
reduction, not immediate treatment of active disease.
